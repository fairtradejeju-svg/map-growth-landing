EP 0112장·1분 50초

학생 등록 (로스터링)

학생 명단 파일을 올리고, 오류가 있으면 고친 뒤 등록을 마칩니다. 오류가 없으면 바로 등록해도 됩니다.

  • 1상단 Rostering 메뉴에서 명단 파일을 올립니다
  • 2오류 목록을 확인하고 파일을 고쳐 다시 올립니다
  • 3오류가 없으면 Post Valid Records 로 등록 완료
  • !계정을 새로 만들면 기존 응시 기록이 넘어오지 않습니다

EP 0211장·1분 39초

시험 세션 만들고 진행하기

시험 볼 학생을 담고 시험 종류를 지정해 세션을 엽니다. 시험이 끝나면 세션을 닫습니다.

  • 1Manage Test Sessions → Find Students to Test, 학교명을 확인하고 검색
  • 2찾은 학생을 Add Students 로 담고 Select Test 에서 시험 지정
  • 3Test Now → 세션 이름·비밀번호를 학생에게 알려줍니다
  • !K-2 · 2-5 · 6+ 학년대를 잘못 고르면 안 됩니다

EP 0310장·1분 27초

시험 결과 보기

반 전체 결과와 학생 한 명의 결과를 화면에서 바로 확인합니다.

  • 1왼쪽 메뉴 MAP Growth Reports 에서 리포트 종류를 고릅니다
  • 2Class Profile — 반 전체의 RIT 점수와 영역별 결과
  • 3Student Profile — 학생 한 명, 과목 탭을 눌러 바꿔 봅니다

EP 048장·1분 14초

Student Progress Report 뽑기

학생별 성장 리포트를 PDF 로 한꺼번에 내려받습니다. 학부모에게 전달할 때 씁니다.

  • 1MAP Growth Reports → Student Progress 카드 → Term 선택
  • 2School 은 이름 글씨를 클릭 (체크박스는 여러 학원을 합칠 때)
  • 3Instructor → 학생 체크 → Create PDF Report
  • 4Reports Queue 에서 ZIP 내려받기 (14일 뒤 삭제)
