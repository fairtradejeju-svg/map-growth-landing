처음부터 끝까지

화면 속 학원명과 학생 이름은 모두 샘플입니다. 노란 테두리와 번호가 눌러야 할 곳, 빨간 표시는 누르면 안 되는 곳이에요.

EP 016장·1분 01초

로그인과 접속

start.mapnwea.org 에 들어가 계정 이메일과 비밀번호로 로그인합니다. 비밀번호를 잊었을 때 다시 만드는 방법까지 담았습니다.

  • 1주소창에 start.mapnwea.org → 계정 이메일 → Continue
  • 2비밀번호 → Sign in
  • 3잊었으면 Forgot Password? → 메일의 Reset password → 새 비밀번호(8자 이상, 대·소문자·숫자·특수문자)
  • !재설정 메일은 스팸함에 들어가기도 하고, 링크는 48시간만 유효합니다

EP 0212장·1분 50초

학생 등록 (로스터링)

학생 명단 파일을 올리고, 오류가 있으면 고친 뒤 등록을 마칩니다. 오류가 없으면 바로 등록해도 됩니다.

  • 1로그인 뒤 첫 화면 위쪽 Rostering → Import Profiles / Rostering
  • 2학기 선택, Standard - Add/Update, 명단 파일 Add
  • 3오류가 있으면 파일을 고쳐 다시 올리고, 없으면 Post Valid Records 로 등록 완료
  • !계정을 새로 만들면 기존 응시 기록이 넘어오지 않습니다

EP 0312장·1분 48초

시험 세션 만들고 진행하기

시험 볼 학생을 담고 시험 종류를 지정해 세션을 엽니다. 시험이 끝나면 세션을 닫습니다.

  • 1위쪽 MAP Growth → Manage Test Sessions → Find Students to Test, 학교명 확인
  • 2찾은 학생을 Add Students 로 담고 Select Test 에서 시험 지정
  • 3Test Now → 세션 이름·비밀번호를 학생에게 알려줍니다
  • !K-2 · 2-5 · 6+ 학년대를 잘못 고르면 안 됩니다

EP 048장·1분 16초

학생 로그인

학생 화면에서 세션에 들어가 시험을 시작하기까지. 실제 학생 화면 그대로입니다.

  • 1test.mapnwea.org · 팝업이 막히면 주소창 끝 표시를 눌러 항상 허용
  • 2Session Name · Password → 이름 고르기 → Next
  • 3Is this correct? 에서 시험 종류 확인 → Yes → 선생님 Confirm 대기
  • 4확인되면 화살표 → 시험 시작
  • !시험 중 창을 닫거나 다른 탭으로 가지 않습니다

MAP 리포트 분석 제너레이터 사용법

NWEA 에서 내려받은 성적 파일을 넣으면 학생별 한글 분석 리포트가 만들어집니다. 계약 학원에 설치해 드리는 프로그램입니다.

  • 1받은 zip 을 압축 풀고 리포트 생성하기 를 두 번 클릭 · 처음 한 번은 바탕화면 아이콘이 생깁니다
  • 2성적 파일(CSV·PDF)을 끌어다 놓고 리포트 생성하기
  • 3다 만들어지면 결과 확인하기 · 학원 폴더 안에 학생별 PDF·HTML 과 요약 엑셀
  • !검은 창은 닫지 않습니다 · 닫으면 프로그램이 멈춥니다

시험 당일 체크리스트

시작 전 6가지

눌러서 체크하면 이 기기에 저장돼요. 다음 시험 땐 초기화 버튼으로 다시 시작하세요.

0 / 6 완료

문제가 생겼을 때

증상 → 해결

자주 생기는 일곱 가지예요. 눌러서 펼치면 해결 순서가 나옵니다. 영상 편 번호를 누르면 해당 화면으로 갑니다.

경고창이 뜨면서 시험이 시작되지 않아요 EP 04 학생 로그인

팝업 차단이 켜져 있을 가능성이 높습니다.

  1. 크롬 주소창 오른쪽 끝의 팝업 차단 표시를 누르기
  2. "이 사이트의 팝업 항상 허용" 선택
  3. 새로고침(F5) 후 다시 시도
"Some student(s) are unable to test" 경고 EP 03 시험 세션

학생 계정이 시험 세션에 제대로 담기지 않았을 때 나옵니다.

  1. 관리자 화면에서 해당 학생의 세션 배정 확인
  2. 학생 이름과 ID가 정확한지 확인
  3. 세션을 다시 시작하거나 학생을 다시 추가
  4. 계속되면 cs@mapgrowthsupportkorea.com으로 문의
시험 중 "temporary error" 메시지가 나왔어요 EP 04 학생 로그인

일시적인 서버 문제입니다. 학생의 진행 상황은 자동으로 저장됩니다.

  1. 5~10초 기다린 뒤 "다시 시도"
  2. 반복되면 인터넷 연결 확인
  3. 그래도 안 되면 브라우저를 닫고 다시 로그인하면 이어서 진행됩니다
해상도 오류(1024×768)가 나와요 EP 04 학생 로그인

MAP 시험은 최소 1024×768 해상도가 필요합니다.

  1. 크롬에서 Ctrl+0(맥은 Cmd+0)으로 확대·축소를 100%로
  2. 전체 화면(F11)으로 전환
  3. 태블릿은 가로로 회전. 화면이 작은 기기는 외부 모니터 연결 권장
비밀번호를 잊어버렸어요 EP 01 로그인
  1. 로그인 화면에서 "Forgot Password?" 누르기
  2. 등록된 이메일 입력
  3. 메일로 받은 링크에서 새 비밀번호 설정(8자 이상, 대·소문자·숫자·특수문자)
  4. 메일이 안 오면 스팸함 확인. 링크는 48시간만 유효합니다
어떤 브라우저를 써야 하나요 체크리스트

크롬(Chrome)을 사용해 주세요. MAP Growth는 크롬에 최적화되어 있고 Safari·Firefox·Edge에서는 일부 기능이 제한될 수 있습니다. 항상 최신 버전으로 업데이트해 주세요.

"Students are Ineligible to Test" 메시지가 떠요 문의

학기 변경에 따른 프로그램 재설정이 필요한 상태입니다. cs@mapgrowthsupportkorea.com으로 연락 주시면 바로 처리해 드립니다.
